# 차량 데이터 기반 연료 유형 분류 모델

> 통계적 기계학습 수업 2인 팀 프로젝트 (인하대학교)
> 전체 분석 과정 및 코드는 [report.pdf](./report.pdf)에 포함되어 있습니다.

## 개요
차량의 엔진 크기, 실린더 수, 연비, CO₂ 배출량 등 성능 데이터를 활용해 연료 유형(디젤 / 일반휘발유 / 고급휘발유)을 분류하는 모델을 개발했습니다. 데이터 전처리부터 모델링, 성능 평가까지 전 과정을 주도적으로 담당했습니다.

## 방법론
- **이상치 탐지**: Mahalanobis Distance 기반 다변량 이상치 탐지
- **다중공선성 진단**: VIF 분석을 통한 변수 간 상관성 확인
- **모델 비교**: 선형 모델(OLS → WLS → Elastic Net)에서 시작해 판별분석(LDA → QDA), 비선형 모델(SVM)까지 단계적으로 비교
  - 각 단계에서 나타난 한계(선형 경계의 한계, 클래스 불균형에 따른 QDA 과적합 등)를 근거로 다음 모델 선택
- **클래스 불균형 처리**: 약 1:20:20 비율의 불균형 데이터에 가중치 조정 및 Stratified K-Fold 교차검증 적용

## 결과
| 지표 | 값 |
|---|---|
| 최종 모델 | Kernel SVM (RBF) |
| Accuracy | 0.75 |
| F1-macro | 0.82 |

- 소수 클래스(디젤) 탐지력을 중요하게 고려해 F2-score 기준으로도 모델 재평가 진행

## 사용 기술
Python, Pandas, NumPy, Scikit-learn, Statsmodels
