# 고객 이탈 예측 (Customer Churn Prediction)

> 고객데이터분석론 수업 개인 과제 (인하대학교)

## 개요
통신사 고객 데이터를 활용해 고객 이탈 여부를 예측하는 LightGBM 기반 분류 모델을 개발했습니다.
데이터 전처리, 피처 선택, 하이퍼파라미터 튜닝, 임계값(Threshold) 최적화까지 전 과정을 진행했습니다.

## 데이터
- 학습 데이터: 4,250건 (20개 컬럼)
- 테스트 데이터: 750건 (20개 컬럼)
- 클래스 분포: 이탈(Yes) 14.07% vs 유지(No) 85.93% (불균형 데이터)

## 방법론
- **변수 분석**: 국제전화 플랜, 통화 시간, 고객서비스 센터 문의 횟수 등 이탈과 상관관계가 높은 변수 파악
- **피처 선택**: 요금 관련 변수 간 다중공선성을 확인하여 중복 변수 제거
- **모델링**: LGBMClassifier 사용
- **하이퍼파라미터 튜닝**: StratifiedKFold(5-fold) 교차검증 + RandomizedSearchCV 방식으로 300회 탐색
- **임계값 최적화**: 0.05~0.95 구간을 세밀하게 탐색하여 F1-Score를 최대화하는 threshold 도출

## 결과
| 지표 | 값 |
|---|---|
| F1-Score | 0.887 |
| Accuracy | 약 94.2% |

- ROC-AUC 기반 모델 성능 검증 수행
- 학습된 모델과 threshold, 피처 정보를 joblib으로 저장해 재사용 가능하도록 구성

## 사용 기술
Python, Pandas, NumPy, LightGBM, Scikit-learn
